# Documentation Maintenance

- When architecture changes materially, update:
	- `AGENTS.md`
	- `docs/implementation_plan.md`
	- any directly affected workflow docs
- When importing gameplay assets, use or update:
	- `docs/templates/asset-intake.md`
	- `docs/templates/texture-budget.md`
	- `docs/templates/physics-object.md`
- When adding NPCs, enemies, or autonomous world behavior, use or update:
	- `docs/templates/behavior-agent.md`
- When introducing new asset or Blender conventions, update:
	- `docs/ai_asset_workflow.md`
	- `docs/blender_local_workflow.md`
- When finishing substantial work, add a session log entry.
