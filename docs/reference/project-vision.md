# Project Vision

`keyArena` is a 3D open-world RPG featuring:
- third-person perspective controls
- character progression and leveling
- a "crafting through discovery" loop
- desktop and mobile input parity as a target direction
- Babylon.js scene runtime with React-driven app composition

Core gameplay loop:
- players loot letters and words from monsters, chests, or world interactions
- letters are collected into inventory
- valid words are crafted from collected letters to unlock progress or power
