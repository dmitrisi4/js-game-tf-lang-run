## Roadside House Offset Fix

- Fixed full-island roadside placeholder placement after visual review showed houses overlapping road surfaces and not reading as aligned to streets.
- Generated houses now keep `roadsideAnchor` metadata with source road center, tangent, side, and road width.
- Full-island transformation now recomputes the final house center from the transformed road anchor after road/building scale is known, preserving road clearance instead of scaling the old Puerto-local offset blindly.
- Reduced the full-island placeholder visual scale multiplier from `2` to `1.35` so boxes read as buildings beside the road overlay instead of oversized blockers covering street lanes.
- Validation: `bun run test src/scenes/environment/tenerifeRoadLayers.test.ts src/scenes/environment/puertoCityConfig.test.ts`, `bun run check`, `bun run test`, and `bun run build` passed.

## Roadside Frontage Row Placement

- Replaced point-sampled roadside placement with straight-segment frontage rows: each eligible road segment lays houses sequentially along its tangent using each building's road-facing depth plus a small gap.
- Increased placeholder building footprints/heights and raised full-island visual scale to `1.55` while preserving road-edge clearance from the transformed centerline.
- Real road data smoke produced 128 anchored generated buildings from `public/data/tenerife/roads-runtime.json`; transformed clearance stayed positive at roughly 1.5 to 2.5 world units from road edge to building footprint.
- Validation: `bun run test src/scenes/environment/tenerifeRoadLayers.test.ts src/scenes/environment/puertoCityConfig.test.ts`, `bun run check`, `bun run test`, and `bun run build` passed.
