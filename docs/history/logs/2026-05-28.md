# Road Overlay Grounding Polish

Date: 2026-05-28

## Scope

Fixed the remaining visual gap between optional Tenerife/Puerto road mesh overlays and player foot grounding. The default `terrain=real` path remains baked-road-first; mesh roads stay a comparison/debug overlay.

## Changes

- Added stable Tenerife road overlay mesh naming helpers in `src/scenes/environment/tenerifeRoadMeshNames.ts`.
- Updated `TenerifeGeoRoadLayers` so road ribbon and junction geometry can sample terrain height at rendered edge vertices, not only at the centerline.
- Reduced road mesh geometric lift and used material depth offset to avoid a visible floating layer.
- Marked road surface and shoulder overlays as pickable visual supports while keeping centerline decorations out of support and leaving physics authority unchanged.
- Updated `AssetPlayerVisual` so the imported player model can anchor feet to road overlay surfaces when those overlays are visible.
- Added focused tests for road mesh names and edge-height road ribbon geometry.
- Updated the Puerto real terrain city task module with Phase 8 planning, acceptance, implementation notes, and validation results.
