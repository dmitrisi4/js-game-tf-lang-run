## Tenerife biome zones & tree placement expansion

### Problem
Trees were too tall (scale 0.32) and only placed in a single upper-mountain region. No zone schema existed to distinguish laurel forest, pine forest, banana farm belt, and the Teide volcanic desert.

### Changes

#### `src/scenes/environment/tenerifeBiomeZones.ts` [NEW]
- Canonical biome zone schema for the Tenerife island (`TenerifeBiomeZoneType`).
- Zones: `teide-volcanic-desert`, `subalpine-scrub`, `canarian-pine-forest`, `laurel-cloud-forest`, `banana-farm-belt`, `coastal-scrub`.
- Each zone defined by `minHeight/maxHeight`, `minSlope/maxSlope`, `minTeideDistance`, optional `maxTeideDistance`, and `northernBias`.
- Exported helpers: `getDistanceToTeide`, `isInsideTeideDesert`, `classifyTenerifeBiome`.
- Coordinate system comments documenting key landmarks (Teide x≈-627, Puerto x≈442, Santa Cruz x≈900).

#### `src/scenes/environment/tenerifeMountainTreeData.ts` [MODIFIED]
- Imports moved to new `tenerifeBiomeZones.ts`; re-exports `TENERIFE_TEIDE_DRY_ZONE_RADIUS` for backward compat.
- **Scale reduced:** `scaleBase` 0.32 → 0.22 (trees ~30% shorter).
- **Height range expanded:** `minSampleHeight` 22 → 12, `minSlope` 0.018 → 0.012 to cover foothill slopes.
- **5 forest regions** replacing the previous single `upper-mountain-belt`:
  1. `upper-pine-belt` — full island high altitude (42–72 m)
  2. `north-laurel-forest` — north coast humid belt (18–58 m, z < 0)
  3. `south-pine-slopes` — southern drier slopes (16–62 m, z > 0)
  4. `east-foothills` — gentle Anaga-adjacent ramps (12–48 m, x > 200)
  5. `west-ridges` — steep Teno terrain (14–60 m, x < -150)
- All regions exclude the Teide dry zone via `isInsideTeideDesert`.
- Combined `maxCount` raised from 900 → 4100 across all regions.

#### `src/scenes/environment/tenerifeMountainTreeData.test.ts` [MODIFIED]
- Updated last test case: `minHeight >= 10` (was 22), all-trees assertion uses exported constant.
- Test name updated to "generates trees across all island slopes (excluding Teide desert)".

### Validation
- `bun run test tenerifeMountainTreeData.test.ts` → 4/4 ✓
- `bun run check` → 150 files, no errors ✓

## Tenerife mountain tree camera-angle visibility fix

### Problem
- Mountain spruce thin instances could disappear when rotating the camera: visible from some angles, missing from others.
- Runtime settlement was healthy (`2589` placements, `2589` visible placements, `86` instanced mesh parts), so this was not a placement-generation failure.

### Root cause
- Imported GLB mesh parts were rendered through thin instances spread across a large island area, but the source meshes could still be selected/camera-culled as normal meshes.
- With camera-angle-dependent frustum checks, stale or insufficient source/thin-instance bounds can drop tree mesh parts even though the thin-instance matrices are valid.

### Changes
- Set `alwaysSelectAsActiveMesh = true` during source mesh preparation and final thin-instance activation in `TenerifeMountainTrees.tsx`.
- Updated `TenerifeMountainTrees.test.ts` to assert the culling guard stays enabled.

### Validation
- `bun run test -- src/scenes/environment/TenerifeMountainTrees.test.ts` → 7/7 ✓
- `bun run check` → 150 files, no errors ✓
- `bun run build` → successful production build ✓
- Browser runtime debug after reload: `placementCount=2589`, `visibleCount=2589`, `instanceMeshCount=86`.
