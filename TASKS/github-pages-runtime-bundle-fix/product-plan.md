# Product Plan

## User-Visible Outcome
- The deployed GitHub Pages game opens without a startup exception.
- Runtime models, textures, and JSON data load under the GitHub Pages project path.
- The page serves the production build artifact generated by GitHub Actions.

## Acceptance Criteria
- `https://dmitrisi4.github.io/js-game-tf-lang-run/` loads the built app without `Class extends value undefined is not a constructor or null`.
- Public assets are requested from `/js-game-tf-lang-run/models/...`, `/js-game-tf-lang-run/textures/...`, and `/js-game-tf-lang-run/data/...` on GitHub Pages.
- Production build uses the configured `/js-game-tf-lang-run/` base path.
- Validation passes locally before deployment.

## Non-Goals
- Reworking scene code or Babylon runtime architecture.
- Performance chunking optimization beyond the immediate runtime fix.
- Replacing or repacking existing model and texture assets.

## Priority
- High: current production deployment fails during module evaluation or misses required public assets.
