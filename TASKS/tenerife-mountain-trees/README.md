# Tenerife Mountain Trees

Add believable tree coverage to Tenerife mountain areas while keeping the Teide volcanic desert visually open.

## Current Follow-Up

Status: Not started

User screenshots from 2026-06-03 show the current tree layer failing the intended read:

- trees appear off to the side of the playable island view and some read as floating over the ocean or horizon;
- the visible Puerto-side mountains and high ridges are mostly empty;
- the task needs a placement reset based on land, elevation, slope, and camera-visible mountain zones, not only generated counts.

The next implementation phase should treat this as an island afforestation pass, with screenshot-visible mountain coverage as the product gate.
